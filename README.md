# FX Tier-1 News Reaction Scanner

A system that detects major macroeconomic news events and tracks
how the foreign exchange market reacts in real time.

## Components

### fx_terminal_scanner
Displays a live terminal dashboard showing currency movement
and market reaction following news releases.

### scanner.py
Continuously scans financial headlines and identifies Tier-1
macro events.

### Event Catalog
Stores historical news events and records the strongest FX
market reactions.
